# How to Update Your Website

## Quick Update Guide

When you want to update your website, you need to replace the files on GitHub. Here's the simplest way:

### Method 1: Replace Files Through GitHub Website (Easiest)

1. Go to your repository at `github.com/your-username/your-username.github.io`
2. Click on the file you want to update (e.g., `index.html`)
3. Click the pencil icon (Edit this file) in the top right
4. Delete all the content
5. Copy the new content from the updated file I gave you
6. Paste it in
7. Scroll down and click "Commit changes"
8. Wait 1-2 minutes for GitHub Pages to rebuild

### Method 2: Upload New Files (For images)

1. Go to your repository on GitHub
2. Click "Add file" → "Upload files"
3. Drag and drop the new image files:
   - profile.jpg
   - lab-selfie.jpg
   - lab-sample.jpg
   - lab-reaction.jpg
4. Scroll down and click "Commit changes"

### Method 3: Delete and Re-upload Everything (Nuclear option)

If you want to start fresh:
1. Go to your repository
2. Click on each old file and delete it (trash icon)
3. Then click "Add file" → "Upload files"
4. Drag ALL the new files at once:
   - index.html
   - styles.css
   - script.js
   - resume.pdf
   - README.md
   - profile.jpg
   - lab-selfie.jpg
   - lab-sample.jpg
   - lab-reaction.jpg
5. Click "Commit changes"

## Checking Your Live Site

After uploading:
1. Wait 1-2 minutes
2. Visit `https://your-username.github.io`
3. Hard refresh (Ctrl+Shift+R on Windows, Cmd+Shift+R on Mac)
4. Your updates should be live!

## Troubleshooting

**Images not showing?**
- Make sure all image files are uploaded
- Check that filenames match exactly (case-sensitive!)
- Wait a few minutes and hard refresh

**Old version still showing?**
- Clear your browser cache
- Try opening in an incognito/private window
- Wait up to 5 minutes for GitHub Pages to rebuild

**Need help?**
- Double-check all files are uploaded
- Make sure your repository is named correctly: `username.github.io`
- Verify GitHub Pages is enabled in Settings > Pages
